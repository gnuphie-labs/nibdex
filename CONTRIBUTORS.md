# nibdex Contributors

This file is the binding record of agreement to the nibdex
[Contributor License Agreement](CLA.md) (the "CLA").

**By adding your line to the Signatures section below — in a commit you author
under your own name and email — you affirm that you have read and agree to the
CLA for that and all future contributions**, as described in the CLA. The commit
is your signature: it is attributable to you and timestamped in the project's git
history.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full how-to.

## How to add your signature

In the same pull request as your first contribution, add one line to the
Signatures section in exactly this format:

```
- Full Name (@github-handle) — YYYY-MM-DD — I have read and agree to the nibdex CLA (CLA.md).
```

The `(@github-handle)` must match the GitHub account opening the pull request —
an automated check (`.github/workflows/cla.yml`) verifies your handle appears here
before a contribution can be merged.

The project maintainer is the recipient of the CLA grant and is not a signatory.
